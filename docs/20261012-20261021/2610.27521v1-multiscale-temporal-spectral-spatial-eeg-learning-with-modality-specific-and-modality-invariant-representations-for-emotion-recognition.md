## 摘要
多模态生理信号为情感识别提供了互补线索，同时也带来了两个相关挑战。情感相关脑电模式会随时间、频带、电极和脑区变化。不同生理模态还同时包含模态特定和共享的情感信息。本文提出 GMSI-Net，一个以脑电为中心的多模态情感识别框架。它包含三个关键组件。时-空-谱-区（TSSR）编码器建模多尺度时间-通道模式、微分熵特征以及局部到全局脑区关系。模态特定表示（MSR）分支使用双向跨模态注意力和可学习门控。它控制信息传递，同时保留模态特定线索。模态不变表示（MIR）分支学习共享情感表示。自适应加权对比损失在模态间对齐该表示。独立的多尺度 Conv-Transformer 编码器处理外周生理信号。GMSI-Net 在 DEAP 和 MAHNOB-HCI 上采用被试内随机十折交叉验证进行评估。模型在 DEAP 上的效价和唤醒度分别达到 96.21 (1.47) 和 96.41 (1.60)。在 MAHNOB-HCI 上分别达到 94.10 (2.86) 和 94.48 (3.77)。这些结果表明，将脑电特征与互补生理信息相结合可以改善情感识别。

## Abstract
Multimodal physiological signals provide complementary cues for emotion recognition. They also raise two related challenges. Emotion-related EEG patterns vary across time, frequency bands, electrodes, and brain regions. Different physiological modalities also contain both modality-specific and shared affective information. This paper presents GMSI-Net, an EEG-centered multimodal emotion recognition framework. It has three key components. The temporal-spatial-spectral-region (TSSR) encoder models multiscale temporal-channel patterns, differential entropy features, and local-to-global brain-region relations. The modality-specific representation (MSR) branch uses bidirectional cross-modal attention and learnable gates. It controls information transfer while retaining modality-specific cues. The modality-invariant representation (MIR) branch learns a shared affective representation. An adaptively weighted contrastive loss aligns this representation across modalities. Independent multiscale Conv-Transformer encoders process the peripheral physiological signals. GMSI-Net is evaluated on DEAP and MAHNOB-HCI using within-subject random ten-fold cross-validation. The model reaches 96.21 (1.47) and 96.41 (1.60) for valence and arousal on DEAP. It reaches 94.10 (2.86) and 94.48 (3.77) on MAHNOB-HCI. These results indicate that combining EEG features with complementary physiological information can improve emotion recognition.

## 1. 核心问题与研究动机

- **背景**：情感计算需要识别人类情感状态，广泛应用于自适应人机交互、辅助技术等。面部表情与语音虽信息丰富，但受光照、背景噪声和情绪外显程度影响；生理信号（EEG、EOG、EMG、ECG、GSR）提供另一类证据，其中 EEG 具有高时间分辨率，外周信号分别反映眼动、肌肉、心脏与皮电反应。
- **挑战一：EEG 表示的多维异质性**。情绪相关 EEG 模式随时间、频带、电极和脑区变化。单一感受野的滤波器会漏掉其他时间尺度的模式；频域描述（如微分熵 DE）缺乏时序顺序信息；独立通道编码缺乏空间关系。已有工作（DGCNN、LGGNet、PGCN、注意力方法）通常把时间、频率、脑区特征放在**分离的通路**中处理，各自压缩后再做图操作，可能丢失时间/频谱信息的来源，难以形成统一的 EEG 表示。
- **挑战二：多模态融合中的信息角色混淆**。不同生理模态的通道数、分布、噪声水平差异大。简单拼接无法区分“有用迁移”与“无关内容”；跨模态注意力虽引入选择性交换，但被注意的特征仍可能含噪；而完全模态不变的公共空间又会丢弃仅存在于单一模态的判别线索。
- **整体含义**：论文提出以 EEG 为中心的多模态框架 **GMSI-Net**，一方面在脑区聚合**之前**统一时-频-空信息，另一方面把“模态特定信息”与“模态共享信息”用两条独立分支分别建模，从而同时保留互补线索与公共情感因素。

## 2. 方法论

### 2.1 总体架构
- 输入：EEG 片段 $X_e\in\mathbb{R}^{C_e\times T_e}$ 与同步外周信号 $X_m\in\mathbb{R}^{C_m\times T_m}$，共 $M$ 个模态。
- EEG 路径用 **TSSR 编码器**；每个外周模态用**独立的多尺度 Conv-Transformer 编码器**；所有编码输出投影到统一特征宽度。
- 融合阶段两条分支：**MSR**（门控双向跨模态注意力，保留模态特异特征）与 **MIR**（共享情感表示 + 自适应加权对比对齐）；二者输出拼接后经 FC+Softmax 分类。

### 2.2 TSSR 编码器（时-空-谱-区）
- **多尺度跨轴注意力（MCA）**：原始 EEG 先嵌入为序列，用多组不同感受野的卷积分支（1×3/1×5/1×7 与 3×1/5×1/7×1）捕获多尺度局部模式；随后在**时间轴与通道轴**两个方向做交叉注意力：
  - 单向注意力 $A^{(k)}_{s\to t}=\mathrm{softmax}\!\left(\frac{Q^{(k)}_t K^{(k)\top}_s}{\sqrt d}\right)V^{(k)}_s$，其中 query 来自时间轴、key/value 来自通道轴，反方向对称；
  - 两个方向的注意力输出与尺度特征拼接，经残差、LayerNorm 与可学习投影得到 $Z_k$，使时间关系与电极关系在进入 DE 与脑区建模前就发生交互。
- **五频带微分熵**：在 δ、θ、α、β、γ 五个频带上，将 EEG 近似为高斯，计算 $h(X)=\frac12\log(2\pi e\sigma^2)$，逐通道提取后与学习到的时-通道特征融合，共同送入图阶段。
- **局部到全局脑区图**：
  - 区域内：可学习滤波更新电极节点特征 $X^{\text{filtered}}_l=\Phi_{\text{ReLU}}(W_{\text{local}}\odot X^{TS}_l-b_{\text{local}})$，再在区域内聚合为 $X_{\text{local}}$；
  - 区域间：以归一化邻接 $\hat A=D^{-1/2}AD^{-1/2}$ 做图卷积 $X_{\text{global}}=\sigma(\hat A X_{\text{local}}W_g)$；
  - 局部滤波保留电极级细节，全局卷积建模区域交互；最终投影对齐外周编码器宽度。主实验采用 **DL 分区**（脑叶划分 + 每叶左右半球细分）。

### 2.3 MSR：模态特定表示
- 对每一对模态 $(A,B)$ 做**双向**门控交互（$A\leftarrow B$ 与 $B\leftarrow A$），$M$ 个模态共 $M(M-1)/2$ 个双向块。

- 可学习门控 $g_{a\leftarrow b}=\sigma\!\left(W_g\,\mathrm{LN}(\mathrm{AvgPool}(\tilde H_{a\leftarrow b}))+b_g\right)$，输出
  $S_{a\leftarrow b}=g_{a\leftarrow b}\odot\tilde H_{a\leftarrow b}+(1-g_{a\leftarrow b})\odot H_a$。
- 残差项保证当跨模态更新无益时仍保留目标模态原特征；门控是**样本级、方向级**的，而非对整个模态施加统一权重。指向同一目标的多个更新被聚合为该模态的 MSR 向量。
