## 摘要
视觉-语言模型（VLMs）在视觉问答（VQA）任务上取得了强劲性能，但当仅有一小部分区域相关时，处理大型杂乱图像的计算成本很高。脑电图（EEG）信号能够捕捉人类对视觉刺激的神经响应，可为感兴趣区域（ROI）提供一种源自人类的语义线索。然而，EEG引导的视觉类别解码仍不完美，这使得直接的ROI路由不可靠。在这项工作中，我们提出BrainFocus，一个用于VQA的可靠、EEG引导的高效VLM框架。一个EEG分类器预测目标类别，YOLO检测器定位匹配的ROI。仅当两个预测均通过置信度阈值时，VLM才接收裁剪后的ROI；否则，它处理完整图像。为进行评估，我们在EEG-ImageNet基础上构建了一个包含40个类别的基准，其中包括生成的杂乱图像和真实的以对象为中心的图像，并带有目标ROI标注和600个英文视觉问答对。在Qwen3.5-VL 2B、4B和9B模型上，BrainFocus在杂乱场景中将VQA准确率提高了4.14-9.87个百分点（pp），同时将输入token和总token分别减少23.2%-39.4%和23.2%-39.3%，并将端到端浮点运算次数（FLOPs）减少23.2%-39.5%。这些结果表明，即使EEG的语义解码不完美，它也能引导高效的VLM推理。

## Abstract
Vision-language models (VLMs) achieve strong visual question answering (VQA) performance, but processing large cluttered images is computationally expensive when only a small region is relevant. Electroencephalography (EEG) signals, which capture human neural responses to visual stimuli, can provide a human-derived semantic cue about the region of interest (ROI). However, EEG-guided visual category decoding remains imperfect, making direct ROI routing unreliable. In this work, we propose BrainFocus, a reliable EEG-guided efficient VLM framework for VQA. An EEG classifier predicts a target category, and a YOLO detector localizes the matching ROI. The VLM receives the cropped ROI only when both predictions pass confidence thresholds; otherwise, it processes the full image. For evaluation, we build on EEG-ImageNet to construct a 40-class benchmark comprising generated cluttered images and real object-centric images, with target-ROI annotations and 600 English visual question-answer pairs. Across Qwen3.5-VL 2B, 4B, and 9B models, BrainFocus improves VQA accuracy by 4.14-9.87 percentage points (pp) on cluttered scenes while reducing input tokens and total tokens by 23.2%-39.4% and 23.2%-39.3%, and end-to-end floating-point operations (FLOPs) by 23.2%-39.5%. These results demonstrate that EEG can guide efficient VLM inference even when its semantic decoding is imperfect.

## 2. 方法论：核心思想与关键技术细节

### 2.1 核心思想
将不完美的 EEG 预测转化为"安全"的输入路由：可靠的 EEG 引导 ROI 送入 VLM，不确定的请求回退到完整图像，从而在保持甚至提升答案质量的同时减少计算。

### 2.2 三阶段 EEG–ROI–VLM 框架
- **Stage 1（EEG 分类器）**：复现 EEG-ImageNet 分类器。输入为 delta/theta/alpha/beta/gamma 五个频段的差分熵特征，送入两层 MLP（隐藏单元 256、128），输出 40 个粗类别上的 top-1 WNID。
- **Stage 2（ROI 检测）**：将图像与预测 WNID 送入在生成杂乱图像上微调的 YOLO 检测器，返回候选框与类别分数；选取与预测 WNID 匹配的置信度最高框；若无匹配框则不返回裁剪。
- **Stage 3（VLM 推理）**：将裁剪 ROI 或完整图像连同同一问题送入 VLM。

### 2.3 双置信度门控回退策略（核心创新）
- **EEG 门**：若 $c_{eeg} < \tau_{eeg}$，跳过 Stage 2，直接使用完整图像。
- **ROI 门**：仅当存在匹配框且 $c_{roi} \ge \tau_{roi}$ 时才裁剪送入 Stage 3，否则回退完整图像。
- **置信度定义**：
  - $c_{eeg} = \max_k \text{softmax}(z)_k$，即最大 softmax 分数（沿用失败预测的经典基线）。
  - $c_{roi}$ 为 YOLO 对最高分匹配框输出的原生置信度。
- **阈值校准**：在 7500 条验证 trial 上，选择在 Precision ≥ 0.97 约束下最大化非回退率的阈值组合，最终得到 $(\tau_{eeg}, \tau_{roi}) = (0.20, 0.05)$。
- **算法流程（Algorithm 1）**：初始化 $I^\star \leftarrow I$；计算 $(\hat{w}, c_{eeg})$；若 $c_{eeg} \ge \tau_{eeg}$ 则求 $(\hat{b}, c_{roi})$，若框存在且 $c_{roi} \ge \tau_{roi}$ 则 $I^\star \leftarrow \text{Crop}(I, \hat{b})$；最后 $\hat{a} \leftarrow \text{VLM}(I^\star, q)$。

### 2.4 语义答案评分
- 两级协议：先对 yes/no 类答案做精确匹配或同义词匹配；短短语答案交由 GPT-5.5 评分，同时附上问题、期望答案、候选答案、答案格式与评估说明，要求给出结果与简要理由以便复核。

- **生成杂乱图像域**：BrainFocus 在全部 12 组"VLM 规模–类别数"组合上准确率提升 **4.14–9.87 pp**，同时输入 token 减少 **23.2–39.4%**、总 token 减少 **23.2–39.3%**、FLOPs 减少 **23.2–39.5%**。

- **类别数影响**：类别数从 10 增至 40，EEG 准确率由 73.11% 降至 48.64%，裁剪覆盖率同步下降，但门控后接受请求的类别精度仍保持 95.95–97.91%（生成域）与 97.31–99.54%（真实域）。

- **效率收益的来源**：token/FLOPs 缩减幅度与裁剪覆盖率强相关——类别数越少、EEG 越准、裁剪越多，节省越大（生成域最多约 39%）；反之在真实以对象为中心图像上，目标本就占据画面主体，裁剪几乎不减少视觉 token，收益自然萎缩到个位数百分比。

## 7. 方法亮点与创新性

- **问题重构的巧思**：不追求提升 EEG 解码精度，而是承认其不完美，用"双置信度门控"把不可靠预测挡在裁剪之前。这是把 EEG 解码从"必须正确"的硬约束，转化为"可拒绝的软建议"的关键一步。
- **端到端但模块化**：三个阶段（EEG 分类 → 目标检测 → VLM 推理）彼此解耦，各阶段可独立升级（更强的 EEG 解码器、更强的检测器、更强的 VLM），无需联合训练，工程可落地性较强。
- **无需改动 VLM 骨干**：属于"输入侧路由"，与视觉 token 压缩、编码器改造、内部剪枝等路线正交，理论上可叠加使用，这扩大了其潜在适用范围。
- **阈值校准有明确约束**：以 Precision ≥ 0.97 为约束最大化非回退率，把"安全"作为第一优先级，符合"错误裁剪会不可逆地删除证据"这一风险结构。
- **评测维度较全**：同时报告准确率、token 缩减、FLOPs 缩减，并给出被试级方差与被试间差异，避免只报均值。

## 9. 启发与未来方向

- **"选择性路由"范式的可迁移性**：该思路可推广到其他含噪生物信号（眼动、fNIRS、EMG）或含噪文本/语音线索，只要存在"可估计置信度 + 可安全回退"的结构。
- **从类别级到实例级**：若 EEG 能提供空间注意力或时序定位信息，配合更精细的目标检测，可能把类别级匹配升级为实例级 ROI 路由，进一步扩大效率收益。
- **置信度估计的改进**：当前 $c_{eeg}$ 只是最大 softmax，属于弱校准信号；引入温度缩放、深度集成、共形预测（conformal prediction）等，可能在不牺牲精度的前提下提高非回退率，从而拿到更多效率收益。
- **与 token 压缩方法叠加**：ROI 裁剪与视觉 token 压缩作用于不同环节，二者结合或可在同一精度下实现更大幅度压缩。
- **面向 VR/AR 的实用化**：论文动机指向穿戴式场景，但 EEG 采集仍需 62 电极湿电极设备，距离消费级 VR/AR 的头带式干电极 EEG 还有较大工程距离。
- **阈值自适应**：可根据用户当前的 EEG 信噪比、图像杂乱程度动态调整门控阈值，而非使用全局固定值。

## 10. 总体评价

BrainFocus 的核心贡献不在于提出更强的 EEG 解码器或更强的 VLM，而在于**把一个看似不可用的含噪信号，通过"拒绝机制 + 安全回退"转化为可用的输入路由线索**。这一思路在方法层面是干净且有说服力的：生成杂乱图像域上 12/12 配置同时获得准确率提升（4.14–9.87 pp）与 23–39% 的 token/FLOPs 缩减，且门控消融清楚展示了"无门控会导致精度下降、有门控才能保住精度"的因果关系，构成了对核心论点的直接证据。

其主要短板集中在**外部效度**：仅一个 VLM 系列、仅粗类别、类别级配对、真实域收益微弱、无横向基线对比、无算力报告。因此更准确的说法是：该工作验证了"含噪 EEG 语义线索 + 门控 ROI 路由"这一范式的**可行性**，而非证明其在通用高效 VLM 场景中具备**竞争力**。若后续能在细粒度类别、实例级配对、多 VLM 系列与更强置信度校准上补齐证据，这一范式有潜力成为穿戴式多模态推理的一条实用路径。
