## 摘要
零样本脑到图像检索需要在含噪EEG响应与视觉表征之间实现稳健对齐。现有EEG-视觉对齐方法通常在传感器空间中操作，并对所有响应施加固定的视觉监督，忽略了头皮EEG中的空间混合以及对齐可靠性在响应层面上的变异性。我们提出一种面向零样本脑到图像检索的自适应皮层约束EEG-视觉对齐方法。该方法将EEG响应重建为预定义的ROI级源模式表征，并使用Neuro-ROI注意力编码器对其进行编码。为处理响应间变异性，我们引入一种基于证据的自适应视觉监督策略，利用基于模型的对齐证据对细节受控的视觉目标进行加权。在THINGS-EEG上，所提方法取得了强大的200类零样本检索性能，ROI级归因则为学习到的源模式表征提供了事后可解释性。这些结果表明，皮层约束的表征学习与自适应监督能够共同支持面向零样本脑到图像检索的EEG-视觉对齐。

## Abstract
Zero-shot brain-to-image retrieval requires robust alignment between noisy EEG responses and visual representations. Existing EEG-vision alignment methods often operate in sensor space and apply fixed visual supervision to all responses, ignoring both spatial mixing in scalp EEG and response-wise variability in alignment reliability. We propose an adaptive cortically constrained EEG-vision alignment method for zero-shot brain-to-image retrieval. The method reconstructs EEG responses into predefined ROI-level source-pattern representations and encodes them with a Neuro-ROI Attention Encoder. To handle response-wise variability, we introduce an evidence-based adaptive visual supervision strategy that weights detail-controlled visual targets using model-based alignment evidence. On THINGS-EEG, the proposed method achieves strong 200-way zero-shot retrieval performance, with ROI-level attribution providing post hoc interpretability of the learned source-pattern representations. These results show that cortically constrained representation learning and adaptive supervision can jointly support EEG-vision alignment for zero-shot brain-to-image retrieval.

# 论文总结：面向零样本脑到图像检索的自适应皮层约束 EEG–视觉对齐

## 1. 核心问题与整体含义（研究动机与背景）

- **任务背景**：零样本脑到图像检索要求模型将一段 EEG 响应与对应但训练中未出现过的图像匹配，核心在于学习稳健的 EEG–视觉跨模态对齐。
- **现有方法的两大缺陷**：
  - **传感器空间操作**：多数方法直接在头皮 EEG 上对齐，而头皮记录因容积传导（volume conduction）是多个皮层源的混合，难以施加解剖结构先验，模型归因也只能停留在电极层面。
  - **固定视觉监督**：对所有 EEG 响应施加同一高细节视觉目标，忽略响应级对齐可靠性的显著差异（神经变异、噪声、注意波动等），对难对齐响应造成过强监督。
- **整体含义**：论文主张将"皮层源约束的表征学习"与"基于证据的自适应监督"结合，既提升对齐性能，又提供 ROI 级事后可解释性。

## 2. 方法论

- **核心思想**：先把 EEG 重建为解剖约束的 ROI 级源模式表征，再用 Neuro-ROI 注意力编码器编码；同时用 Dempster-Shafer（DST）证据理论对细节受控的视觉目标做响应级自适应加权。

- **关键技术细节**：
  - **皮层约束 ROI 源表征**：
    - 线性前向模型 `X = Gs + ε`；仅用刺激前基线段估计噪声协方差 `Cn`（不使用诱发响应/标签）。
    - 计算 MNE 逆算子 `W_MNE = (GᵀCn⁻¹G + λI)⁻¹GᵀCn⁻¹`，得到源估计。
    - 施加 **dSPM 归一化**降低深度偏置，再按 **HCP-MMP1** 分区选取双侧预定义 ROI（V1/V2/V3/hV4/VO/PHC/MT/MST/LO/IPS 等），得到 `Y ∈ R^{S'×T}`。
    - 因无个体 MRI，源估计被视为"ROI 模式表征"而非精确皮层源。
  - **细节受控视觉目标**：
    - 用**中心凹模糊（foveated blur）**生成 L/M/H 三档细节图像，模糊半径 `{rL, rM, rH} = {61, 21, 3}`。
    - 用冻结的 DINO-RN50 提取嵌入 `t(L), t(M), t(H)`，作为监督目标（明确声明为"操作探针"，非神经视觉细节的直接测量）。
  - **Neuro-ROI 注意力编码器**：
    - 学习参数 `α`，经 softmax 得单纯形权重 `w`，对源通道重加权 `Ỹ = diag(w)Y`。
    - 展平后经残差 MLP（Linear–GELU–Dropout–Linear–LayerNorm–L2）投影为源模式嵌入 `z`。
  - **基于证据的自适应视觉监督（DST）**：
    - 辨识框架 `Θ={L,M,H}`，BPA `m_i=[mL,mM,mH,mΩ]`，`mΩ` 显式表示无知。
    - **两类证据源**（以中细节目标为稳定参考）：① 响应级 InfoNCE 损失 `ℓi`（越大越难→偏 L）；② 对齐 margin `μi = sii − max_{j≠i}sij`（越大越易→偏 H）。
    - **鲁棒归一化**：用 EMA 平滑的 30%/70% 运行分位数将统计量映射到 [0,1]。
    - **统计→证据锚定**：映射到序数细节尺度上的原型距离，经温度 softmax（T=0.5）得到证据向量。
    - **冲突→无知转换**：`inc_i` 为两证据向量的半 ℓ1 差异，`mΩ = clamp(β0 + β1·inc_i, ε, 0.5)`（β0=0.15, β1=0.3, ε=0.05）。
    - **顺序融合与折扣**：每 epoch 用 Dempster 规则融合历史 BPA，再以 δ=0.95 折扣。
    - **Pignistic 变换**：`q_{i,k} = m_k + mΩ/3`，得到响应级对齐可靠性后验。
    - **期望对比损失**：`L_expected = (1/B)Σ_i Σ_k q_{i,k}·ℓ(k)_i`。
  - **总体目标**：`L_total = L_anchor + λ_exp·L_expected`，其中 `L_anchor` 为中细节目标的对称交叉熵（防止塌缩到低细节目标），`λ_exp = 0.2`。

## 3. 实验设计

- **数据集**：THINGS-EEG（10 名被试，RSVP 范式）。训练 1654 概念×10 图×4 次；测试 200 概念×80 次，训练/测试概念不重叠。
- **Benchmark**：**200 路零样本脑到图像检索**，指标为 Top-1 / Top-5 准确率，含**被试内（intra-subject）**与**被试间（inter-subject，留一被试）**两种设置。
- **对比方法**：BraVL、NICE、NICE-SA、NICE-GA、ATM-S、CognitionCapturer（CogCap）、VE-SDN、UBP。
- **预处理差异**：沿用 ATM-S 流程但**去除 MVNN**（避免破坏与固定 lead field 的兼容性），改用 dSPM 源重建 + ROI 选择，并对重复响应做源后平均。
- **消融实验**：逐一移除 CIC（冲突→无知）、PT（Pignistic 变换）、HFD（历史证据融合+折扣）、ECL（期望对比损失）四个模块。
- **附录扩展实验**：4 种视觉编码器（DINOv2 ViT-B/14、DINO ViT-B/8、ViT-B/16、RN50）；6 种 EEG 编码器（DeepNet、EEGProject、ShallowNet、EEGNet、TSConv、Neuro-ROI）。
- **诊断性分析**：响应级 pignistic 后验分布、按主导细节目标的检索准确率分层、后验可靠性分层、ROI 级归因（注意力 + Integrated Gradients）及跨被试一致性。

## 6. 主要结论与发现

- **检索性能**：被试内 **56.7% Top-1 / 83.0% Top-5**，显著超过最强基线 UBP（50.9%/79.7%）；被试间 Top-1 为 13.0%，具竞争力，但 **Top-5（31.5%）未一致超越所有基线**，跨被试迁移仍受限。
- **消融**：完整策略最佳；各模块移除带来小幅但一致的下降，说明设计整体稳定。
- **后验分层**：按主导目标，高细节主导响应检索准确率 82.0%、中细节 56.0%、低细节仅 9.0%；分层后 86.9% → 61.0% → 10.7% 呈单调梯度，且与响应级 InfoNCE 损失一致变化。
- **后验分布特征**：边际均值接近均匀（qL=0.341, qM=0.317, qH=0.342），但响应级分化强烈（42.8% 低细节主导、42.3% 高细节主导），符合"对齐证据跟踪器"的预期。
- **ROI 归因**：跨被试高度一致（注意力 0.922、IG 0.915），归因集中于 **PHA 海马旁皮层、IPS1、MT、LO** 等高级视觉/背侧通路区域，而非仅早期视觉区。
- **总体结论**：皮层约束表征学习与自适应监督可协同支撑零样本脑到图像检索，并带来 ROI 级可解释性。

## 7. 优点

- **引入解剖先验**：用 ROI 级源模式替代传感器空间，缓解容积传导导致的混合，并使归因可映射到皮层区域。
- **显式建模响应级不确定性**：用 DST 的 ignorance 质量处理冲突证据，避免对难对齐响应的过强监督，思路新颖。
- **细节受控目标 + 锚点损失**：用中心凹模糊构造有序监督层级，并以中细节锚点防止塌缩到低细节平凡解。
- **可解释性落地**：结合注意力与 IG 两种归因，并量化跨被试一致性，增强了结论的可信度。
- **对比全面**：同时评估视觉编码器与 EEG 编码器两类变量，验证方法泛化性。

## 8. 不足与局限

- **目标代理性**：细节受控目标仅由模糊操作构造，**不是完整的语义层级**，也不代表真实神经视觉细节表征。
- **源定位不精确**：缺少个体结构 MRI，采用**模板源重建 + 预定义 ROI**，归因反映的是可重复的模型相关模式，而非精确皮层发生源。
- **响应粒度**：使用**重复平均**的刺激特异源表征，而非单次呈现试次，与真实在线场景有差距。
- **控制实验缺失**：未做随机 ROI、非视觉 ROI、传感器空间归因等对照，ROI 归因结论偏描述性。
- **数据覆盖有限**：仅 THINGS-EEG 单一数据集，缺乏跨数据集与更自然刺激的验证。
- **性能局限**：被试间 Top-5 未一致提升；消融增益较小，各模块独立贡献难以强证明。
- **后验解释风险**：后验分析基于已知对应关系且为事后进行，不能作为神经细节状态的独立证据；存在过度解读的潜在风险。
