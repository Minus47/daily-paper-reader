## 摘要
零样本脑到图像检索需要在带噪脑电响应与视觉表示之间实现稳健对齐。现有的脑电-视觉对齐方法通常在传感器空间中操作，并对所有响应施加固定的视觉监督，忽略了头皮脑电中的空间混合以及对齐可靠性的逐响应差异。我们提出了一种面向零样本脑到图像检索的自适应皮层约束脑电-视觉对齐方法。该方法将脑电响应重建为预定义的ROI级源模式表示，并用Neuro-ROI注意力编码器对其进行编码。为处理逐响应差异，我们引入了一种基于证据的自适应视觉监督策略，利用基于模型的对齐证据对细节受控的视觉目标进行加权。在THINGS-EEG上，所提方法取得了较强的200路零样本检索性能，ROI级归因则为学习到的源模式表示提供了事后可解释性。这些结果表明，皮层约束表示学习与自适应监督能够共同支持面向零样本脑到图像检索的脑电-视觉对齐。

## Abstract
Zero-shot brain-to-image retrieval requires robust alignment between noisy EEG responses and visual representations. Existing EEG-vision alignment methods often operate in sensor space and apply fixed visual supervision to all responses, ignoring both spatial mixing in scalp EEG and response-wise variability in alignment reliability. We propose an adaptive cortically constrained EEG-vision alignment method for zero-shot brain-to-image retrieval. The method reconstructs EEG responses into predefined ROI-level source-pattern representations and encodes them with a Neuro-ROI Attention Encoder. To handle response-wise variability, we introduce an evidence-based adaptive visual supervision strategy that weights detail-controlled visual targets using model-based alignment evidence. On THINGS-EEG, the proposed method achieves strong 200-way zero-shot retrieval performance, with ROI-level attribution providing post hoc interpretability of the learned source-pattern representations. These results show that cortically constrained representation learning and adaptive supervision can jointly support EEG-vision alignment for zero-shot brain-to-image retrieval.

## 一、核心问题与整体含义（研究动机与背景）

- **任务背景**：零样本脑到图像检索（zero-shot brain-to-image retrieval）要求模型将一段脑电响应匹配到对应的、训练中从未见过的图像，其核心是学习稳健的脑电-视觉跨模态对齐。
- **现有方法的两个关键缺陷**：
  - **传感器空间操作**：多数方法直接在头皮电极空间做对齐。由于容积传导（volume conduction），头皮记录是多皮层源活动的空间混合，既无法将解剖结构作为归纳偏置，也使模型归因难以超越电极层面总结。
  - **固定视觉监督**：现代预训练视觉嵌入包含大量细粒度信息，但刺激特异的脑电响应在对齐可靠性上差异显著；对所有响应施加同一高细节视觉目标，会引入不可靠监督，掩盖逐响应差异。
- **整体含义**：作者主张同时引入**皮层源约束**（ROI 级源模式表示）与**逐响应的自适应监督**（基于模型对齐证据加权细节受控视觉目标），以同时提升检索性能与事后可解释性。

## 二、方法论：核心思想与关键技术

**核心思想**：将脑电从传感器空间重建为解剖约束的 ROI 级源模式表示，用 ROI 约束注意力编码；再用 Dempster-Shafer 证据理论对低/中/高三种细节受控视觉目标做逐响应自适应加权，使难对齐响应获得更保守的监督。

### 1. 皮层约束 ROI 级源表示
- 线性前向模型：`X = Gs + ε`（G 为导联场，s 为固定朝向下的皮层源时序）。
- 仅用**刺激前基线段**估计噪声协方差 `Cn`，按数据划分得到 `Ctr_n`、`Cte_n`，构造 MNE 逆算子：
  `W_MNE = (GᵀCn⁻¹G + λI)⁻¹GᵀCn⁻¹`
- 源估计后做 **dSPM 标准化**抑制深度偏置：`ŝ_dSPM(j,t) = ŝ_MNE(j,t) / sqrt((W_MNE·Cn·W_MNEᵀ)_jj)`
- 按 **HCP-MMP1** 分区选取双侧预定义 ROI，形成 `Y ∈ R^{S'×T}`，后续编码全部在该 ROI 级表示上进行。

### 2. 细节受控视觉目标（操作性探针）
- 对图像施加**中央凹模糊变换**：先用半径 `rk` 的圆盘核均匀模糊，再与原因像按空间变化混合图 `α(i,j)=exp(-λ·‖·‖₂/L)` 混合。
- 三档半径 `{rL, rM, rH} = {61, 21, 3}`，对应低/中/高细节；用冻结的 DINO-RN50 提取嵌入 `t(k) = φ(Ĩ(k))`。
- 明确声明：该操作是"响应级对齐证据"的**操作性探针**，并非对神经视觉细节表示的直接测量。

### 3. Neuro-ROI 注意力编码器
- 学习参数向量 `α ∈ R^{S'}`，经 softmax 得单纯形权重 `w = softmax(α)`。
- 用 `w` 重加权源通道：`Ỹ = diag(w)·Y`，展平后经残差 MLP + LayerNorm 得 `d` 维源模式嵌入 `z`。
- 学到的 `w` 量化各 ROI 源的相对贡献，形成模型相关的空间结构摘要。

### 4. 基于证据的自适应视觉监督（DST）
- 识别框架 `Θ = {L, M, H}`，另设无知集 `Ω = Θ`；维护 BPA `mi = [mL, mM, mH, mΩ]`，和为 1。
- **证据构建**（以中细节目标 `t(M)` 为稳定参考）：
  - 逐响应 InfoNCE 值 `ℓi`：越大表示越难对齐 → 偏向低细节；
  - 对齐间隔 `μi = sii − max_{j≠i} sij`：越大表示越易区分 → 偏向高细节。
- **稳健归一化**：用 EMA 平滑的运行分位数（30%、70%）把 `x ∈ {ℓ, μ}` 映射到 `[0,1]`。
- **统计量→证据锚定**：在序数细节尺度（L=0, M=0.5, H=1）上映射为原型距离 `d`，再经温度 `T=0.5` 的 softmax 得两类证据向量。
- **冲突→无知转换**：用半 L1 差异衡量两证据源的不一致 `inc_i`，`mΩ = clamp(β0 + β1·inc_i, ε, 0.5)`，`β0=0.15, β1=0.3, ε=0.05`；单元素质量按两证据均值缩放 `(1−mΩ)`。
- **序贯证据融合与折扣**：每个 epoch 用 Dempster 规则与历史 BPA 融合（含冲突项 K），再做 `δ=0.95` 的逐 epoch 折扣。
- **Pignistic 变换与期望对比损失**：`qi,k = mi,k + mΩ/|Θ|`，最小化 `L_expected = (1/B) Σi Σk qi,k · ℓ(k)_i`。
- **总目标**：为防止坍塌到低细节目标，保留中细节锚定损失 `L_anchor = L_SCE^(M)`，最终 `L_total = L_anchor + λ_exp·L_expected`，`λ_exp = 0.2`。

## 三、实验设计

- **数据集**：THINGS-EEG（10 名被试，RSVP 范式）。训练 1,654 概念 ×10 图 ×4 次重复；测试 200 概念 ×1 图 ×80 次重复；训练/测试概念不相交。
- **预处理**：沿用 ATM-S 流程但**去掉 MVNN**（会改变传感器协方差，与固定导联场不兼容），改用 dSPM 源重建 + 预定义 ROI 选择；源重建后对同一刺激的重复做平均以提升 SNR（即样本为刺激特异、被试特异的平均响应，而非单次试次）。
- **主评测基准**：200 路零样本脑到图像检索，报告 Top-1 / Top-5，分**被试内**与**被试间（留一被试）**两种设置。
- **对比方法**：BraVL、NICE、NICE-SA、NICE-GA、ATM-S、CognitionCapturer (CogCap)、VE-SDN、UBP。
- **消融实验**：对自适应监督的四个模块逐一移除——CIC（冲突→无知）、HFD（历史证据融合与折扣）、PT（pignistic 变换）、ECL（期望对比损失）。
- **附加实验**：不同视觉编码器（DINOv2 ViT-B/14、DINO ViT-B/8、ViT-B/16、RN50）；不同脑电编码器（DeepNet、EEGProject、ShallowNet、EEGNet、TSConv 对比所提 Neuro-ROI Attention Encoder）。
- **事后分析**：对 2,000 条被试内测试响应做 pignistic 后验分层；ROI 级归因（基于注意力与 Integrated Gradients 两种方法）及跨被试一致性分析。

## 六、主要结论与发现

- **检索性能**：被试内 200 路零样本检索达 **56.7% Top-1 / 83.0% Top-5**，优于最强基线 UBP（50.9%/79.7%）；被试间 Top-1（13.0%）具竞争力，但 Top-5（31.5%）未全面超越所有基线，作者归因于模板源重建下跨被试迁移受限。
- **消融**：完整自适应监督配置最优（56.7%/83.0%），移除任一模块均带来小幅一致下降。
- **后验分层**：响应级后验均值接近均匀（qL≈0.341, qM≈0.317, qH≈0.342），但逐响应分化强烈（高/低细节各占约 42%）；按主导目标分层，高细节主导响应检索准确率 **82.0%**、低细节主导仅 **9.0%**；三档可靠性分层呈单调梯度（86.9% → 61.0% → 10.7%）。
- **可解释性**：跨被试 ROI 重要性剖面高度一致（注意力归因平均 Pearson 相关 0.922，IG 归因 0.915）；归因集中于高级视觉与背侧通路区域（PHA 子区、IPS1、LO、MT 等），而非仅早期视觉区。
- **总体结论**：皮层约束表示学习与自适应监督可协同支撑检索导向的脑电-视觉对齐，并提供 ROI 级可解释性。

## 七、优点

- **方法论创新点清晰**：将 EEG 源重建（MNE + dSPM + HCP-MMP1 ROI）与跨模态对比学习结合，把解剖结构作为归纳偏置，缓解容积传导导致的传感器空间混叠。
- **监督策略有理论支撑**：用 Dempster-Shafer 证据理论显式建模"无知"，通过冲突→无知转换和 pignistic 变换避免过自信决策，比简单加权更具可解释性。
- **规避坍塌的设计**：保留中细节锚定损失，防止模型退化为全部对齐低细节目标。
- **可解释性验证扎实**：同时使用注意力与 Integrated Gradients 两种互补归因方法，并量化跨被试一致性，结果相互印证。
- **学术态度严谨**：多处明确界定方法的解释边界（如视觉目标是"操作探针"、后验是"模型基于对齐可靠性的估计"而非神经真值），并诚实报告被试间性能的不足。

## 八、不足与局限

- **视觉细节代理不完整**：细节受控目标由模糊生成，只是可用视觉细节的操作性代理，不能代表完整的语义层级。
- **源重建精度受限**：缺乏个体结构 MRI，采用模板源重建与预定义 ROI，ROI 归因仅表明可复现的模型相关源模式组织，**不等于精确的皮层发生源**。
- **样本粒度问题**：分析基于重复平均的刺激特异源表示，而非原始单次呈现试次，与真实在线应用场景有差距。
- **缺少源空间对照分析**：未做随机 ROI 集、非视觉 ROI 对照或传感器空间归因对比，归因结论只能描述性解读。
- **单数据集局限**：仅在 THINGS-EEG 上验证，缺乏跨数据集泛化证据。
- **消融增益有限**：各模块绝对贡献小，
