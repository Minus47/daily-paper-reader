## 摘要
零样本脑到图像检索需要噪声脑电响应与视觉表示之间的稳健对齐。现有脑电-视觉对齐方法通常工作在传感器空间，并对所有响应施加固定的视觉监督，忽略了头皮脑电中的空间混合以及对齐可靠性在响应间的变异性。我们提出一种面向零样本脑到图像检索的自适应皮层约束脑电-视觉对齐方法。该方法将脑电响应重建为预定义的 ROI 级源模式表示，并使用 Neuro-ROI Attention Encoder 对其进行编码。为处理响应间的变异性，我们引入一种基于证据的自适应视觉监督策略，该策略利用基于模型的对齐证据对细节受控的视觉目标进行加权。在 THINGS-EEG 上，所提方法取得了优异的 200 类零样本检索性能，且 ROI 级归因提供了所学源模式表示的事后可解释性。这些结果表明，皮层约束表示学习与自适应监督能够共同支持面向零样本脑到图像检索的脑电-视觉对齐。

## Abstract
Zero-shot brain-to-image retrieval requires robust alignment between noisy EEG responses and visual representations. Existing EEG-vision alignment methods often operate in sensor space and apply fixed visual supervision to all responses, ignoring both spatial mixing in scalp EEG and response-wise variability in alignment reliability. We propose an adaptive cortically constrained EEG-vision alignment method for zero-shot brain-to-image retrieval. The method reconstructs EEG responses into predefined ROI-level source-pattern representations and encodes them with a Neuro-ROI Attention Encoder. To handle response-wise variability, we introduce an evidence-based adaptive visual supervision strategy that weights detail-controlled visual targets using model-based alignment evidence. On THINGS-EEG, the proposed method achieves strong 200-way zero-shot retrieval performance, with ROI-level attribution providing post hoc interpretability of the learned source-pattern representations. These results show that cortically constrained representation learning and adaptive supervision can jointly support EEG-vision alignment for zero-shot brain-to-image retrieval.

## 1. 核心问题与整体含义（研究动机与背景）

- **任务背景**：零样本脑到图像检索（zero-shot brain-to-image retrieval）要求模型把一段 EEG 响应与对应的、训练中从未见过的图像匹配起来，即在神经表征与视觉表征之间建立共享嵌入空间。
- **EEG 的可用性与难点**：EEG 具有毫秒级时间分辨率、采集成本低，是实用的神经信号源；但空间分辨率低、响应变异大，使跨模态对齐困难。
- **现有方法的两大缺陷**：
  - **传感器空间（sensor space）建模**：头皮 EEG 因容积传导（volume conduction）是多个皮层源的混合信号，直接在此空间对齐难以把解剖结构作为归纳偏置，模型归因也只能停留在电极层面，难以概括。
  - **固定视觉监督**：现代预训练视觉嵌入包含大量细粒度信息，但刺激特异的 EEG 响应在"对齐可靠性"上差异很大。对所有响应一视同仁地施加同一高细节视觉目标，会带来不可靠监督，掩盖响应间的变异性。
- **整体含义**：论文主张应同时引入（a）**皮层源约束**（把 EEG 重建到预设 ROI 级源模式）与（b）**响应自适应的视觉监督**（按模型对齐证据动态加权不同细节层级的目标），从而在提升零样本检索性能的同时获得 ROI 级事后可解释性。

## 2. 方法论

### 2.1 核心思想
将传感器空间 EEG → 皮层约束的 ROI 级源模式表示 → 用 ROI 约束的源通道注意力编码 → 用 Dempster-Shafer 证据理论按响应级对齐证据，自适应地在"低/中/高细节"三个视觉目标间分配监督权重。

### 2.2 皮层约束 ROI 级源表示（第 3.2 节）
- 线性前向模型：`X = G s + ε`，`G` 为导联场矩阵，`s` 为皮层源时间序列（固定朝向约束）。
- 仅用**刺激前基线段**估计噪声协方差 `C_n`，按划分分别得到 `C_n^tr`、`C_n^te`，**不使用诱发响应、视觉目标或类别标签**。
- 最小范数估计（MNE）逆算子：`W_MNE = (Gᵀ C_n⁻¹ G + λI)⁻¹ Gᵀ C_n⁻¹`。
- 用 **dSPM** 标准化以减轻深度偏置：`ŝ_j,t^dSPM = ŝ_j,t^MNE / sqrt([W_MNE C_n W_MNEᵀ]_jj)`。
- 按 **HCP-MMP1** 分区选取双侧预定义 ROI，得到 `Y ∈ R^{S'×T}`，后续所有编码都在该 ROI 级表示上完成。
- ROI 家族：V1、V2、V3、hV4、VO、PHC（PHA1/2/3）、MT、MST、LO（LO1/2/3）、IPS（IPS0–IPS5）；ROI 选择为先验假设驱动、与下游检索性能无关。

### 2.3 细节受控视觉目标（第 3.3 节）
- 作为"操作性探针"（operational probe），而非神经视觉细节的直接测量。
- 用**圆盘核模糊**生成均匀模糊图（半径 `r_L=61 > r_M=21 > r_H=3`，`r_H` 最接近清晰图）。
- 用空间变化的混合图 `α(i,j)=exp(−λ‖(i,j)−(i₀,j₀)‖₂/L)`（λ=0.3）模拟**中央凹视觉**，把原图与模糊图混合得到 `Ĩ^(k)`。
- 用冻结视觉编码器 φ（默认 DINO-RN50）提取 d 维嵌入，得到目标集合 `{t^(L), t^(M), t^(H)}`。

### 2.4 Neuro-ROI 注意力编码器（第 3.4 节）
- 学习参数向量 `α ∈ R^{S'}`，经 softmax 得到单纯形权重 `w`，对源通道重加权：`Ỹ = diag(w) Y`。
- 展平为 `y = vec(Ỹ)`，经残差 MLP 投影（Linear→GELU→Dropout→Linear + 残差）、LayerNorm、L2 归一化得到源模式嵌入 `z`。
- `w` 本身可量化各 ROI 源估计的相对贡献，构成 ROI 级空间归因。

### 2.5 基于证据的自适应视觉监督（第 3.5 节）
- **识别框架** `Θ = {L, M, H}`，BPA `m_i = [m_i^L, m_i^M, m_i^H, m_i^Ω]`，`Σm = 1`，`Ω=Θ` 表示"无知"（ignorance）。
- **两类模型对齐证据**（以中细节目标 `t^(M)` 为稳定参考）：
  - 每响应 InfoNCE 值 `ℓ_i`：越大代表越难对齐 → 偏向低细节；
  - 对齐边际 `μ_i = s_ii − max_{j≠i} s_ij`：越大代表越易区分 → 偏向高细节。
- **稳健归一化**：用 EMA 平滑的 30%/70% 运行分位数 `θ^(30)`、`θ^(70)` 将 `x ∈ {ℓ, μ}` 映射到 `[0,1]`（式 12）。
- **统计量到证据的锚定**：映射到序数细节尺度上的原型距离（0、0.5、1 分别对应 L、M、H），再经温度 T=0.5 的 softmax 得到类别证据（式 13–15）。
- **冲突转无知**：用半 ℓ1 差异度量两证据源的不一致 `inc_i`，令 `m_i^Ω = clamp(β₀ + β₁·inc_i, ε, 0.5)`（β₀=0.15, β₁=0.3, ε=0.05），单体质量由两证据向量平均后按 `(1 − m_i^Ω)` 缩放得到（式 16–18）。
- **序贯证据融合与折扣**：每 epoch 用 **Dempster 组合规则**把历史 BPA 与当前 BPA 融合（先算冲突 K），再按 δ=0.95 做 epoch 级折扣（式 19–20）。
- **Pignistic 变换与期望对比损失**：`q_{i,k} = m_i^k + m_i^Ω/|Θ|`，最小化 `L_expected = (1/B) Σ_i Σ_k q_{i,k} · ℓ_i^(k)`（式 21–22）。高无知质量 → `q` 更平坦 → 监督更保守。

### 2.6 总体目标（第 3.6 节）
- 为防止所有响应塌缩到"低细节"平凡解，保留中细节目标作为**稳定锚点**：`L_anchor = L_SCE^(M)`（对称交叉熵）。
- 总损失：`L_total = L_anchor + λ_exp · L_expected`，主实验取 `λ_exp = 0.2`。

## 6. 主要结论与发现

- **检索性能**：被试内设置下达到 **56.7% Top-1 / 83.0% Top-5**，优于最强基线 UBP（50.9% / 79.7%）；跨被试设置 Top-1 为 13.0%，具竞争力，但 **Top-5（31.5%）并未稳定超越所有基线**（UBP 33.4%、ATM-S 33.7%）。
- **消融结论**：完整证据自适应监督最优（56.7 / 83.0）；移除 CIC、HFD、PT 或 ECL 都会带来小幅但一致的下降，说明各设计选择共同贡献。
- **后验分析发现**：
  - 边际均值接近均匀先验（q_L=0.341、q_M=0.317、q_H=0.342），但响应间差异明显（平均响应级标准差 0.152）；42.8% 由低细节主导、42.3% 由高细节主导、仅 15.0% 由中细节主导。

  - 按后验分层：高细节证据层（n=582, 29.1%）准确率 **86.9%**、无知质量最低（0.16）；低细节/高无知层（n=861, 43.1%）仅 **10.7%**；呈现 86.9% → 61.0% → 10.7% 的单调梯度。
- **归因发现**：跨被试 ROI 重要性高度一致——注意力归因平均两两 Pearson 相关 **0.922**，IG 归因 **0.915**。注意力偏向 PHA 亚区、背侧顶叶 IPS1 与外侧枕叶；IG 稳定突出 **IPS1**，次要贡献来自 MT 与 PHA 亚区。说明模型依赖分布式的高层视觉与背侧通路 ROI 源模式，而非仅早期视觉区。
- **总体结论**：皮层约束表示学习与自适应监督可协同支持面向零样本脑到图像检索的 EEG–视觉对齐，并附带 ROI 级可解释性。
