## Abstract
Electroencephalogram (EEG) classification is critical for applications ranging from medical diagnostics to brain-computer interfaces, yet it remains challenging due to the inherently low signal-to-noise ratio (SNR) and high inter-instance variability. To address these issues, we propose LAtte, a novel framework that integrates a Lorentz Attention Module with an InceptionTime-based encoder to enable robust and generalizable EEG classification. Unlike prior work which focused primarily on single-subject performance, LAtte focuses on cross-subject generalization. First, we learn a shared baseline signal across all subjects using pretraining tasks to capture common underlying patterns. Then, we utilize low-rank adapters to learn subject-specific embeddings that model individual differences. This allows a single model to be trained concurrently for all subjects without maintaining separate sets of weights for each individual. We evaluate LAtte on three widely-used EEG benchmarks, achieving a substantial improvement in performance over current state-of-the-art methods.

## 1. 核心问题与研究动机

- **研究背景**：脑电图（EEG）分类在医疗诊断和脑机接口等领域具有重要应用价值，但长期以来面临两大核心挑战：
  - **信噪比极低**：EEG信号容易受到噪声和伪迹干扰，有效信息提取困难。
  - **个体间差异大**：不同受试者的脑电信号模式存在显著差异（如解剖结构、皮层折叠模式、电极位置差异等），导致模型难以跨受试者泛化。

- **核心问题**：已有EEG分类模型主要聚焦于**单受试者**（subject-dependent）场景的性能提升。当模型被直接应用到新受试者时，由于个体差异带来的数据分布偏移，其泛化性能通常显著退化。因此，**跨受试者（cross-subject）泛化**是一个尚未充分解决的挑战。

- **现有方法的局限**：
  - 不同受试者之间的共享特征与个性化特征未被显式分离建模。
  - 为每个受试者维护独立权重会带来巨大的参数开销，且难以扩展到大规模多受试者场景。
  - 直接训练“一刀切”的共享模型会因个体差异过大而难以收敛或过拟合到特定受试者。

## 2. 方法论

### 2.1 核心思想（高屋建瓴）

LAtte的核心主张是：**将EEG信号中的“跨受试者共享模式”与“个体特异模式”进行显式分离，并在一个统一框架中同时建模两者**。共享模式通过预训练获得（作为基线信号），个体差异则通过轻量级适配器捕获。整体上，论文遵循一个“**先共性后个性**”的两阶段建模策略。

### 2.2 整体框架架构

LAtte框架包含三个关键组件：

- **步骤一：预训练共享基线编码器**
  - 在所有受试者的混合数据上执行预训练任务，目标是学习一个**共享的基线信号表示**，捕获所有受试者共有的底层神经活动模式。这些任务可以包括重建任务或对比学习等自监督形式，使编码器在初始阶段就具备捕捉通用EEG模式的能力。
  - 这个预训练得到的编码器构成了后续所有受试者共同的骨干网络。

- **步骤二：InceptionTime编码器**
  - 基于预训练得到的共享基线，使用**InceptionTime**架构作为骨干编码器来提取EEG信号的时域特征。InceptionTime包含多个不同卷积核尺寸的并行分支，能够从多尺度捕捉时间动态模式。
  - 该编码器接收预处理后的原始EEG信号作为输入，输出高层特征表示。

- **步骤三：Lorentz注意力模块**
  - 这是论文的核心创新点。与传统的欧几里得空间注意力机制不同，LAtte在**双曲空间（Hyperbolic Space）**中操作，具体采用**Lorentz模型**。
  - 核心动机：EEG信号具有层次结构和较大的个体差异，双曲空间具有“指数增长”的容量特性，能更自然地在嵌入空间中同时容纳共享的全局层级结构与个体特有的局部差异。
  - 模块功能：通过双曲空间中的注意力计算（利用Lorentz距离/内积来度量不同时间步或通道之间的相似性），让模型在聚合特征时能够更好地保持层级结构信息。

- **步骤四：低秩适配器（Low-Rank Adapters）**
  - 当进行特定受试者的分类任务时，LAtte**不更新共享编码器的主干权重**，而是为每个受试者学习一组**低秩适配器参数**（类似LoRA）。这些适配器以受试者嵌入（subject embedding）为条件，通过低秩分解方式在共享编码器的基础上施加轻量级、个性化的偏移。
  - 这样做的好处是：所有受试者共享同一个骨干模型，无需为N个受试者维护N套完整权重；同时，每个受试者通过适配器获得了个性化的特征变换，从而有效建模个体差异。

### 2.3 流程描述

1. 在全体训练受试者的EEG数据上预训练InceptionTime编码器，获得共享初始权重；
2. 对每个受试者，引入条件化的低秩适配器，在共享编码器的特征上施加个体偏移；
3. 将共享特征与个体适配后的特征输入Lorentz注意力模块，在双曲空间中进行特征加权聚合；
4. 最终经过分类头输出分类结果（如睡眠分期类别或运动想象类别）。

训练方式是**联合训练**：所有受试者的数据被混合送入同一个模型，但通过受试者ID条件化的适配器为每个受试者保留了个性化路径——文中称其为“无需为每个个体维护独立权重集的单模型并发训练机制”。
