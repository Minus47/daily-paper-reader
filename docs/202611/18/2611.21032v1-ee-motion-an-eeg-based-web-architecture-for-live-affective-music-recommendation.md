## 摘要
音乐聆听与情绪本质相连，而情绪在单次聆听过程中会持续漂移。尽管现代浏览器已可与可穿戴脑机接口交互，推荐系统仍围绕离散日志构建，缺乏整合连续生理信号的基础设施。此外，现有的情感感知模型依赖静态用户画像与离线训练，无法在不重新训练模型的情况下服务于匿名新用户。我们提出一个可同时解决这两类挑战的Web平台。该系统通过Web Bluetooth与消费级脑电（EEG）头带配对，实时采集EEG，将额叶alpha不对称性与唤醒指数映射为Russell环形情感平面上归一化的效价-唤醒代理坐标。在这些坐标的驱动下，一个情感适配器将结构各异的推荐骨干统一到共享的实时评分机制之下。通过少量喜爱的曲目对匿名访客进行参数化，该模块以实时代理坐标为条件推荐曲目。这表明，实时EEG导出的控制信号能够在无需持久化用户表或模型重新训练的情况下引导推荐。

## Abstract
Music listening is intrinsically tied to emotion, which drifts continuously within a single session. Although modern browsers interface with wearable brain-computer interfaces, recommendation systems remain structured around discrete logs and lack the infrastructure to integrate continuous physiological signals. Furthermore, existing affect-aware models rely on static user profiles and offline training, failing to serve anonymous newcomers without model retraining. We present a web platform that resolves both challenges. Pairing with a consumer electroencephalogram (EEG) headband over Web Bluetooth, the system captures live EEG, mapping frontal alpha asymmetry and arousal index to normalized valence-arousal proxy coordinates on Russell's circumplex plane. Driven by these coordinates, an affective adapter unifies structurally diverse recommendation backbones under a shared live scoring mechanism. By parameterizing anonymous visitors through a few favorite tracks, the module recommends tracks conditioned on live proxy coordinates. This demonstrates that real-time EEG-derived control signals can steer recommendations without persistent user tables or model retraining.
